# Mobile based IoT Project
## Project Goals
- Mobile app that controls a fan power.
- Communicate to the *Esp32* Microcontroller through *MQTT* protocol using **HiveMQ**.
- It secures a TLS/SSL connection to he *MQTT* borker.

### Description
The mobile app allows user to pick between three levels along with communicating with an AI agent.
When the AI agent responds with a level (1, 2, 3) it changes the fan level which corresponds to the power of the fan.
